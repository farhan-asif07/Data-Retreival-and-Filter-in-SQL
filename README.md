# SQL Lab  – Data Retrieval and Filtering in SQL

## Project Overview

This repository contains practical SQL queries developed as part of Database Management Systems (DBMS) Lab 

The lab focuses on retrieving, filtering, and sorting data from a relational database using SQL. The exercises are based on **BookVerse**, an online bookstore database containing book information such as titles, authors, categories, prices, and publication years.

## Learning Objectives

- Retrieve complete records using `SELECT *`.
- Select specific columns from database tables.
- Filter records using `WHERE`.
- Apply logical operators such as `AND`, `OR`, and `NOT`.
- Use comparison operators for conditional filtering.
- Sort records using `ORDER BY`.
- Perform pattern matching using `LIKE`.
- Filter multiple values using `IN` and `NOT IN`.
- Retrieve records within a range using `BETWEEN`.
- Combine filtering and sorting operations.

## Lab Challenges

1. Find the three most expensive books.
2. Display books containing "Data" in the title, sorted by author.
3. Retrieve all books except those in the Comics category.
4. List books published between 2015 and 2020.
5. Identify authors who have written more than one book using `GROUP BY`, `COUNT()`, and `HAVING`.

## Technologies Used

- **Database:** MySQL
- **Development Tool:** MySQL Workbench
- **Language:** SQL
- **Version Control:** Git and GitHub

## How to Run

1. Open MySQL Workbench and connect to your MySQL server.
2. Select the BookVerse database created during the previous labs.
3. Ensure the `Books` table contains the required records.
4. Open the SQL script from this repository.
5. Execute queries individually and examine their results in the Result Grid.

## Conclusion

This lab demonstrates fundamental SQL operations for retrieving and analysing database records. It provides hands-on experience with data selection, conditional filtering, sorting, pattern matching, and basic aggregation.

These concepts form the foundation for writing more advanced database queries.
